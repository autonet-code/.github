# Autonet

**Decentralized AI training and inference.**

An intelligence-based financial system. A framework for a peaceful and orderly transition of responsibilities from humans to machines.
Recursive Principial Body with self-referencing and self-maintaning governance, economic, and judicial mechanisms.


---

## Core Infrastructure

### [Autonet Node](https://github.com/autonet-code/node)
Atomic environment running the novel consensus mechanism where computational contribution is measured by intelligence output, not arbitrary work. The foundation of Autonet's economic model. The user-facing termianal (https://autonet.computer) features an Agent orchstration framework with fractal topology, parent-child inboxes, cascading budgets, and schedulers. (only works with a valid Claude Max subscription at the moment).

### [On-Chain Jurisdiction](https://github.com/dOrgTech/trustless-business)
Legal and governance framework for autonomous entities. Integrates with Autonet to enable machine participants with real-world standing. Related apps: [werule.io](https://werule.io) | [trustless.business](https://trustless.business)
